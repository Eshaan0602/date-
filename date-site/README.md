# Our Date Adventure 💗

A little romantic date-planner mini-game. Static site — just `index.html` + `assets/`, no build step needed.

## Deploy it (free, ~2 minutes)

**1. Put it on GitHub**
- Go to https://github.com/new, create a new repository (e.g. `our-date-adventure`), keep it Public or Private, don't add a README.
- On the empty repo page, click "uploading an existing file".
- Drag in `index.html` and the whole `assets` folder from this zip.
- Click "Commit changes".

**2. Deploy on Vercel**
- Go to https://vercel.com and sign in (you can sign in with your GitHub account).
- Click "Add New… → Project".
- Select the `our-date-adventure` repo you just created and click "Import".
- Leave all settings as default (it's a static site, no framework/build command needed) and click "Deploy".
- After ~30 seconds you'll get a live link like `https://our-date-adventure.vercel.app` — that's the one you send her. It works great on phones.

That's it — no domain, no server, no cost.

## Editing later
- Want to swap in your own Cinema poster image? Add a file named `cinema-poster.jpg` next to `index.html` (same folder), then push/redeploy.
- Want a different background photo? Replace `assets/table.jpg` with a new image (keep the same filename), then push/redeploy.
- Any change you push to the GitHub repo will auto-redeploy on Vercel within a minute.
